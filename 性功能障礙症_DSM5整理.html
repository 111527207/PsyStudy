本章導論
性功能障礙症 — 本章概覽
Sexual Dysfunctions Overview
▾
本章核心特點：性功能障礙是一群異質性組成的疾病，其特徵為個體對於性反應或感受到性愉悅的能力有臨床上顯著的困擾。個體可同時有數個性功能障礙，每一種都應給予診斷。
本章包含的9個診斷
  • 遲洩（Delayed Ejaculation）
  • 勃起障礙症（Erectile Disorder）
  • 女性高潮障礙症（Female Orgasmic Disorder）
  • 女性性興趣／興奮障礙症（Female Sexual Interest/Arousal Disorder）
  • 骨盆性器疼痛／插入障礙症（Genito-Pelvic Pain/Penetration Disorder）
  • 男性性慾低落障礙症（Male Hypoactive Sexual Desire Disorder）
  • 早洩（Premature/Early Ejaculation）
  • 物質／醫藥引發的性功能障礙症
  • 其他特定的／非特定的性功能障礙症
⚠️ 重要排除原則
  • 若性事困難是因性刺激不充足造成，不需給予性功能障礙診斷（雖仍可能需要照護）
  • 若能被其他非性精神疾病大部分解釋（如憂鬱症、雙相情緒障礙症、焦慮症、PTSD、精神病）→ 只需診斷該精神疾病
  • 若由物質/醫藥使用或中斷較佳解釋 → 診斷物質/醫藥引發的性功能障礙症
  • 若由其他一般身體病況造成（如骨盆神經損傷）→ 不需精神科診斷
  • 若嚴重關係苦惱、伴侶暴力或顯著壓力源能更好解釋 → 不下性功能障礙診斷，改列V碼/Z碼呈現關係問題
通用亞型架構（適用於大多數性功能障礙症）
  • 終生（lifelong）：性問題從第一次性經驗就開始
  • 後天（acquired）：在一段相對正常功能時期後才發生
  • 一般型（generalized）：不限於特定刺激、情境或伴侶
  • 情境型（situational）：只在特定刺激、情境或伴侶時發生
評估時應納入考慮的五大因素（幾乎所有疾病皆適用）
  • ① 伴侶因素（伴侶的性事問題、健康狀態）
  • ② 關係因素（溝通不良、性活動渴望不一致）
  • ③ 個人易感性因素（身體形象差、性/情緒虐待病史）、精神疾病共病（憂鬱、焦慮）或壓力源（失業、傷慟）
  • ④ 文化或宗教因素（禁止性活動或性愉悅的相關抑制、對性的態度）
  • ⑤ 與預後、病程、治療相關的醫學因素
302.74 F52.32
遲洩
Delayed Ejaculation
▾
⭐ 核心：射精顯著延遲或無法射精，且非自願
A
以下任一症狀必須在大部份或所有與伴侶的性行為時經驗過（約75%-100%），個人並無意拖延：
  • 顯著的射精拖延
  • 顯著的不常或沒射精
B
準則A症狀持續至少約六個月
C
準則A症狀引起個人臨床上顯著苦惱
D
性功能障礙無法以非性精神疾病、嚴重人際關係苦惱結果、或其他顯著壓力做更好的解釋，且無法歸因於物質/醫藥效應或另一身體病況所致
  • 終生 / 後天
  • 一般型 / 情境型
  • 嚴重度：輕度/中度/重度（依苦惱程度）

核心特徵為顯著的延遲或無法達到射精。男人指出儘管有充足的性刺激及想射精的欲望，依然有困難或無法達到射精。「延遲」的定義沒有精確的界限，尚無共識多久才是不可接受的。

男人和伴侶可能提出要達成高潮有過久插入，直到精力耗竭或性器不適才停止努力；有些男人因反覆射精困難而避免性行為；性伴侶可能因無法輕易讓對方射精而感到性吸引力減少。

因缺乏精確定義，盛行率不清楚。這是男性最不常見的性抱怨。只有75%男人提出每次性行為都會射精，少於1%抱怨超過6個月的難以射精。

終生遲洩在早期性經驗就開始發病且持續終生。後天遲洩在一段正常性功能期後才開始。遲洩盛行率似乎在50歲左右呈現相對穩定，之後發生率開始顯著增加（80幾歲後是小於59歲時的兩倍）。

基因和生理
與年齡有關的快速傳導周邊感覺神經喪失，以及與年齡有關的性類固醇分泌下降，可能與50歲以上男人遲洩增加有關。

遲洩抱怨在不同國家和文化間有差異，亞洲男性族群較多於歐洲、澳洲或美國的男性族群，差別可能與文化或基因的不同有關。

射精困難可能造成性交困難，通常與伴侶或雙方相當程度的心理苦惱有關。

⭐ 鑑別重點
⭐ 其他身體狀況
區分可由一般醫學疾病或損傷完全解釋的遲洩，和心因性、特發性或合併原因的遲洩。情境型抱怨提示心理因素。神經退化性疾病（多發性硬化症、糖尿病、酒精性神經病變）、手術創傷（腰部交感神經節、腹會陰手術、腰部交感神經切除術）可導致無法射精。
逆行性射精（Retrograde ejaculation）
射精入膀胱，可能發生在經尿道攝護腺刮除術之後，需與遲洩鑑別。
物質/醫藥使用
抗憂鬱劑、抗精神病藥、交感神經藥物、鴉片類藥物會造成射精問題。
高潮功能障礙
射精與高潮通常但不總是一起發生。無快感射精（anhedonic ejaculation）：射精正常但愉悅減少，不能編碼為遲洩，可編碼為其他特定/非特定性功能障礙症。

有些證據顯示遲洩可能更常發生於嚴重型重度憂鬱症上。

302.72 F52.21
勃起障礙症
Erectile Disorder
▾
⭐ 核心：三大症狀中至少一項，反覆達成或維持勃起失敗
A
以下三項症狀至少一種出現，需在大部分或所有（約75%-100%）性行為時經驗過：
  • 性行為中欲勃起，有顯著困難
  • 欲維持勃起持久來完成性行為，有顯著困難
  • 勃起硬度顯著減弱
B
準則A症狀持續至少約六個月
C
準則A症狀引起臨床上顯著苦惱
D
性功能障礙無法以非性精神疾病、嚴重人際關係苦惱結果、或其他顯著壓力做更好的解釋，且無法歸因於物質/醫藥效應或另一身體病況所致
  • 終生 / 後天
  • 一般型 / 情境型
  • 嚴重度：輕度/中度/重度（依苦惱程度）

核心特徵是在與伴侶的性交中反覆地達成或維持勃起失敗。須以仔細性史查明此問題已呈現顯著時間（至少約6個月），且在大部分性行為場景（至少75%時間）下發生。

許多勃起障礙症男人可能有低自尊、低自信、男子氣概減少，也可能感覺情緒憂鬱。害怕和/或避免未來性機遇可能發生。伴侶的性滿足減少和性慾減少很常見。

13-21%
40-80歲男人偶爾有勃起問題
40-50%
60-70歲以上抱怨顯著勃起問題
~2%
小於40-50歲經常有勃起問題

大約20%男人在第一次性經驗時害怕有勃起問題，大約8%感覺有勃起問題而無法插入。

第一次性行為勃起失敗與不認識的伴侶性交、同時使用藥物/酒精、不想要性行為、同儕壓力有關，大多會自行緩解。後天勃起障礙症通常與生物因素有關（糖尿病、心血管疾病），在大部分男人可能持續；終生勃起障礙症較與心理因素有關，為自限性或對心理介入有反應性。

氣質
神經質人格特質可能與大學生勃起問題有關；屈從性人格特質可能與40歲以上男人有關。述情障礙症（Alexithymia）在「心因性」勃起障礙症男人身上很常見。勃起問題在憂鬱症或PTSD男人上很常見。
病程修飾因子
後天勃起障礙症風險因子：年齡、吸菸、缺乏運動、糖尿病、性慾下降。

勃起障礙症抱怨在不同國家間有差異。這是代表不同文化期待的差別，還是純粹是勃起失敗發生頻率的差別，尚未可知。

夜間陰莖勃起試驗（NPT）：若快速動眼期有充足勃起則顯示心因性問題。其他評估：都卜勒超音波、血管內注射血管活性藥物、動力注射海綿體造影、陰部神經傳導檢查（疑周邊神經病變時）、血清游離睪固酮、甲狀腺功能、空腹血糖（篩檢糖尿病）、血脂評估（40歲以上勃起障礙可預測未來心血管疾病風險）。

會干擾生育，造成個體和人際苦惱，害怕和/或避免性機遇可能干擾親密關係的形成。

⭐ 鑑別重點
⭐ 重度憂鬱症
重度憂鬱症和勃起障礙症兩者緊密相關，勃起障礙症伴隨嚴重憂鬱疾患也可能發生。
正常勃起功能
需考慮有正常勃起功能但有過多期待的男人。
⭐ 物質/醫藥使用
發病與物質/醫藥開始使用不謀而合，且症狀消散伴隨中斷或減量，顯示有物質/醫藥引發的性功能障礙症。
⭐ 其他身體狀況
最困難的鑑別部分。年齡>40-50歲和/或有身體病況，需考慮血管疾病。器質性因素造成的勃起功能障礙通常是廣泛性且逐漸發病；脊髓損傷例外。情境型、非持續性、生活壓力事件後急性發生的勃起問題最常是心理性；年齡<40歲也顯示心理原因。
其他性功能障礙
可能與早洩和男性性慾低落障礙症共存。

可與早洩、男性性慾低落障礙症、焦慮症、憂鬱症共病。在攝護腺增生相關下泌尿道症狀的男人上很常見。可能與血脂異常、心血管疾病、性腺功能低下、多發性硬化症、糖尿病等共病。

302.73 F52.31
女性高潮障礙症
Female Orgasmic Disorder
▾
⭐ 核心：高潮拖延/罕有/缺乏，或高潮感受強度顯著降低
A
以下任一症狀是在大部份或所有（約75%-100%）性行為時經驗過：
  • 高潮明顯拖延，高潮不常有或完全沒有
  • 高潮的感受明顯降低
B
準則A症狀持續至少約六個月
C
準則A症狀引起臨床上顯著苦惱
D
性功能障礙無法以非性精神疾病、嚴重人際關係苦惱結果（如伴侶暴力）、或其他顯著壓力做更好的解釋，且無法歸因於物質/醫藥效應或另一身體病況所致
  • 終生 / 後天
  • 一般型 / 情境型
  • 特別註明：從未在任何情境下有性高潮
  • 嚴重度：輕度/中度/重度

一般而言，並不支持特定人格特質或精神病理學與高潮功能障礙之間有關聯。患有此症者對討論性事有較大困難，但整體性滿足並不強烈與高潮經驗相關（許多女性即使很少或沒有高潮，仍表示有很高程度性滿足）。

10-42%
女性高潮問題盛行率（依不同因素變化）
~10%
女人終生不會經驗到高潮

這些估計都沒有將苦惱納入考量，只有一部分經驗高潮困難的女人也會說出相關苦惱。

終生型表示高潮困難一直存在；後天型是在一段正常高潮功能期後才發展出。女人第一次經驗到高潮的年齡變化很大。女人高潮一致性的比率，手淫時比與性伴侶性行為時還要高。

氣質
焦慮和擔心懷孕等廣泛心理因素可能影響經驗高潮的能力。
環境
關係問題、身體健康、心理健康，與女人高潮困難有很強關聯性。
基因和生理
多發性硬化症、子宮全切除術導致骨盆神經損傷、脊髓損傷會影響高潮功能。SSRI已知會延遲或抑制高潮。外陰陰道萎縮患者比無此狀況者更顯著抱怨高潮困難。停經狀態不與高潮困難有一致關聯。基因因素可能對高潮功能差異有顯著影響。

女人缺乏高潮被認為需要治療的程度，在不同文化間可能不同；高潮對性滿足的重要性也不同。無法達到高潮的盛行率可從17.7%（北歐）至42.2%（東南亞）。

女人高潮時有可測量的生理變化（荷爾蒙、骨盆底肌肉、大腦活性改變），但個體差異很大。臨床上診斷是根據女人自己的報告。

功能性後果並不清楚。雖然關係問題和高潮困難有很強的關聯性，但關係因素是風險因子或結果，尚不清楚。

⭐ 鑑別重點
⭐ 重度憂鬱症
對所有或幾乎所有活動興趣或喜樂顯著減少的特徵，可能可以解釋女性高潮障礙症；若可被其他精神疾病解釋則不下此診斷。
物質/醫藥引發的性功能障礙症
物質/醫藥使用可能解釋高潮困難。
其他身體病況
若因多發性硬化症、脊髓損傷等則不下此診斷。
人際因素
嚴重關係苦惱、親密伴侶暴力或其他顯著壓力源可解釋時，不下此診斷。
⭐ 陰蒂刺激依賴
若女性在陰蒂刺激時能達到高潮，但無法在性交時達到，不符合女性高潮障礙症診斷。
性刺激不足
需評估是否因性刺激不足造成插入困難，這種狀況不應診斷此疾病。

可能同時存在女性性興趣／興奮障礙症。重鬱症等其他非性精神疾病可能經驗到降低的性興趣/興奮，間接增加高潮困難可能性。

302.72 F52.22
女性性興趣／興奮障礙症
Female Sexual Interest/Arousal Disorder
▾
⭐ 核心：6項中至少3項，缺乏或明顯降低性慾，持續≥6個月
A
缺乏或明顯降低性慾，以下症狀至少出現三種：
  • 對性活動無／降低興趣
  • 對性幻想無／降低興趣
  • 無／降低起始性活動，且對性伴侶的起始邀約無感
  • 大部分或所有（約75%-100%）性行為經驗中，對性行為無／降低興奮／愉悅感
  • 對任何內在或外在性／色情暗示（如書面、口語、視覺）無／降低性興趣／興奮
  • 大部分或所有性行為經驗中，對生殖部位或非生殖部位無／降低感覺
B
準則A症狀持續至少約六個月
C
準則A症狀引起臨床上顯著苦惱
D
性功能障礙無法以非性精神疾病、嚴重人際關係苦惱結果（如伴侶暴力）、或其他顯著壓力做更好的解釋，且無法歸因於物質/醫藥效應或另一身體病況所致
  • 終生 / 後天
  • 一般型 / 情境型
  • 嚴重度：輕度/中度/重度
⚠️ 重要概念：性慾不同步（Desire Discrepancy）
女人對性活動的欲望比伴侶低，此並不足以診斷為女性性興趣／興奮障礙症。

不同女人之間的症狀呈現可能有變化。性慾和興奮通常同時困難是此疾病患者的抱怨特徵。短期的性興趣或興奮轉變很常見，可能是調適性反應，不代表性功能障礙。

若終生缺少性慾是對於自認為「無性戀」的較佳解釋，則不應診斷此疾病。

時常與經驗高潮有困難、性活動之間經驗疼痛感、不常有性活動、和伴侶間性慾不同步等問題相關。關係困難和情緒障礙症也是常見相關特質。對性興趣或興奮的「適切」程度不實際期待，伴隨差的性技巧和缺少性資訊也可能明顯。

盛行率未知。性慾低落和性興奮問題的盛行率（DSM-IV/ICD-10定義）可能有顯著差異。較年老的女人比年輕女人較少有低性慾的苦惱，即使性慾可能隨年齡降低。

終生型表示缺少性興趣或興奮在整個性生活都會呈現。擁有較長伴侶關係的女性比短伴侶關係者比較能從事性行為，即使一開始沒有明顯性慾。年長女性陰道乾燥可與年紀和更年期有關。

氣質

不同文化間性慾低下盛行率有很大不同，東亞女人比歐美女人更常見。可能反映文化對性興趣較少，或量化工具的人為誤差。需考量不同文化會將某些行為病態化，而其他文化則不會。

盛行率和發生率尚不清楚，似乎因低報緊急治療的性功能副作用。海洛因濫用者比安非他命或MDMA濫用者性功能副作用比率較高。

抗憂鬱劑誘發的性功能障礙症可能早至第一次服藥後第8天就發生。大約30%輕度至中度高潮延遲個體會在6個月內自行緩解。SSRI誘發的性功能障礙症可能持續至停藥之後。尼古丁和酒精的副作用可能不會出現，直到使用數年之後。有些證據顯示物質/醫藥相關的性功能困擾隨年齡增加。

文化：文化因素、醫藥對性功能的作用、個體對這些變化的反應，彼此之間可能互相影響。

性別：性功能副作用可能存在性別差異。

醫藥引發的性功能障礙症可能會導致醫藥不順從（noncompliance）。

時序關係症狀先於物質/醫藥使用，或停用後仍持續症狀在物質/醫藥啟用、劑量增加或停用之後出現

本質個體本身的性反應能力受損外在刺激/技巧不足，非個體功能問題

⚠️ 評估要點
幾乎所有性功能障礙症的鑑別診斷都包含「性刺激是否足夠」的評估，這是臨床決策的重要分支點。
鑑別要點單純性功能障礙症重度憂鬱症伴隨性功能症狀
核心特徵局限於性功能領域的特定困擾對所有或幾乎所有活動的興趣或喜樂顯著減少（廣泛性）
診斷處理下性功能障礙診斷若性功能困難完全可被憂鬱症解釋 → 只診斷憂鬱症，不另加性功能障礙診斷

性功能障礙症診斷決策流程
▾
⭐ 國考臨床推理流程
Step 1 — 排除性刺激不足
評估性經驗中性刺激是否足夠。若不足為主因 → 不給予性功能障礙診斷（可能需其他臨床照護）。
Step 2 — 排除其他精神疾病的更佳解釋
是否能被重度憂鬱症、雙相情緒障礙症、焦慮症、PTSD、精神病症做更好的解釋？若是 → 只診斷該精神疾病。
Step 3 — 排除人際/情境因素
是否有嚴重關係苦惱、伴侶暴力或顯著壓力源能更好解釋？若是 → 不下性功能障礙診斷，列V碼/Z碼。
Step 4 — 排除物質/醫藥及身體病況
症狀是否與物質/醫藥使用時序相關？是否由其他一般身體病況（神經、血管、內分泌疾病）造成？
→ 物質/醫藥相關：診斷物質/醫藥引發的性功能障礙症
→ 純身體病況：不需精神科診斷
Step 5 — 確定症狀所屬性反應週期階段
  • 慾望期問題 → 男性性慾低落障礙症 / 女性性興趣興奮障礙症
  • 興奮期/插入問題 → 勃起障礙症 / 骨盆性器疼痛插入障礙症
  • 射精/高潮期問題 → 早洩 / 遲洩 / 女性高潮障礙症
⚠️ 共病處理原則
個體可同時有數個性功能障礙，每一種都應給予診斷（非互斥關係，與其他DSM-5章節「單一發作期僅一診斷」的原則不同）。
